Many Functions, Then Fewer

A Gaussian process doesn’t fit one curve. It puts a probability distribution over whole functions. Before any data it allows a wide spread of smooth functions. Each observation rules out the ones that don’t pass near it.

Watch the prior over functions become a posterior, one observation at a time.

Somewhere there is a hidden true function, here sin(x). The GP never sees it, only the observed points. Everything drawn is about the function f(x) itself, not about new noisy readings of it.

Math

The prior mean is 0 and the prior covariance is the RBF kernel. Observations are y = f(x) + ε, with ε ~ N(0, σ²).

K(x, x′) = exp(−(x − x′)² / (2ℓ²))

posterior mean = k*T(K + σ²I)−1y

posterior covariance = K** − K*T(K + σ²I)−1K*

x1, …, xN
the inputs you have observed (the dots’ horizontal positions).
y
the list of observed values, one per dot.
K
the N × N training Gram matrix: how strongly the kernel says each pair of observed inputs is related.
σ²I
observation noise variance on the diagonal. With σ = 0 the model trusts every y exactly.
k*, K*
kernel values between the observed inputs and the inputs being predicted: a column for one test point, a matrix for the whole plotted grid.
K**
kernel values among the test inputs themselves: the prior covariance before any data.
ℓ
the length scale: roughly how far apart two inputs can be and still say a lot about each other.

The mean line is the first formula at 201 points across the axis. The band is mean ± 2 × the square root of the diagonal of the second. A possible function is mean + Lz, where L LT is the whole posterior covariance and z is a list of independent standard normals, so neighboring points in one sample move together.

Nothing is inverted directly. The page factors K + σ²I = L LT (Cholesky) and solves two triangular systems. It always adds a jitter of 10−8 to the diagonal, and more if needed, so a repeated input (two identical rows in K) still factors. That jitter is why “zero” uncertainty at a noise-free point is really about 10−4.

Model settings

wigglysmooth

How far one observation’s influence reaches. Small ℓ: functions change quickly and the band reopens soon after each point. Large ℓ: slowly varying functions, and one point informs a wide stretch.

noise-freeσ = 1

How far a y may sit from f(x). It changes how the model reads all the points, and sets the noise on preset and sampled points added from now on. The band never includes it: it shows uncertainty about f, not about the next reading.

Things to try

Pinch the band

  • Add three preset points. With noise-free, the mean goes through each one and the band shrinks to a point there.
  • Notice the band stays narrow near a point too, not only on it. Inputs within about ℓ are strongly related.

Loosen with noise

  • Now drag the noise up to 0.3. The mean stops threading every dot, and the band at each dot opens up.
  • The model now believes each dot is f plus a random nudge, so it won’t chase any single one.

Repeat an input

  • In “height you clicked” mode, click twice at the same x, once high and once low.
  • Noise-free, the mean settles on their average. Add noise and the two become two readings of one f(x).

Change the ruler

  • With a few points, slide ℓ to 0.2: possible functions turn wiggly and the band reopens between points.
  • Slide to 3: the functions become nearly straight over the gaps and the band stays tight much farther out.
