Where Do You Draw the Line?

A classifier doesn’t hand you an answer. It hands you a score, and somebody still has to decide how high is high enough. Move that line and you trade one kind of mistake for the other — you can’t have fewer of both. The ROC curve is the picture of every line you could have drawn, and the point riding on it is the one you actually did.

The cost ratio is literally a slope on the ROC plot. Expected cost is c·P·(1−TPR) + N·FPR, so holding cost fixed traces a straight line of slope N / (c·P). Slide that gold ruler up and to the left until it only just touches the curve: the touching point is the cheapest place to operate. Change c and the ruler tilts, so the best point slides along a curve that never moved.

This is Murphy’s cost-sensitive rule from §5.1.2.2. With a false negative c times as expensive as a false positive, call it positive once p(y=1|x) ≥ 1/(1+c). At c = 2 that is a threshold of 1/3 — you declare positive on much weaker evidence, because missing one hurts more.

Zero-one loss is just the special case c = 1. Then the threshold is 0.5 and “pick the most probable class” is optimal. That rule isn’t a law — it’s what you get when you assume both mistakes hurt exactly the same.

TPR and FPR are each computed inside one true class. TPR only ever divides by the number of real positives; FPR only by the number of real negatives. Rescale how many of each you have and both are untouched — so the ROC curve simply does not know about class imbalance. That is sometimes exactly what you want, and sometimes a trap.

Precision divides along the other direction — down a column, across both true classes. With 2% positives, even a 5% false alarm rate buries the real ones, and precision falls through the floor while the ROC curve looks just as handsome as before. This is Murphy’s §5.1.3.3, and it is why a precision-recall curve is the honest chart for a rare-event problem.

The three formulas

ŷ(x) = I( score(x) ≥ τ )

The whole decision rule. One number in, one comparison, one label out. Everything else on this page is a consequence of which τ you pick.

TPR = TP / (TP + FN)    FPR = FP / (FP + TN)

Of the real positives, how many did we get? Of the real negatives, how many did we wrongly flag? Each divides by one row of the matrix — which is exactly why neither one cares how many of each class there are.

pick ŷ = 1  iff  p(y=1|x) ≥ 1 / (1 + c)

Where to put the line, if you know what mistakes cost. Read it as: the threshold is the cost of a false alarm divided by the cost of both mistakes together.
